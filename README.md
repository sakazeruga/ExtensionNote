# 📝 WebMemo

Webページにメモを貼れるChrome拡張機能です。

---
##Updates
Youtube等の属性に対応
---


## なんで唐突にこんなの作ったの？
GmailのSimpleNoteを普段使ってるんですが、
G's Academyの課題である、LocalStorage利用を前提としたアプリで、
実用性を考えた結果、地味に欲しかった拡張機能のコイツを作りました。
One Tabは量がエグいことになるんで、整理整頓したいと思ってたんですよ。
Chrome拡張機能の都合上デモページ作れないんですが、
GithubからDLするだけなんで大目に見てください…。

---

## これ何？

いつも見るWebページに「後でここ確認する」「パスワードのヒント」「感想」などのメモを残せます。  
次にそのページを開いたとき、右上にメモがポコッと表示されます。

## インストール方法

> Chromeウェブストアには未公開です。以下の手順で手動インストールしてください。

### 1. このリポジトリをダウンロード

右上の緑の **「Code」** ボタン → **「Download ZIP」** をクリック

![download](https://docs.github.com/assets/cb-47413/mw-1440/images/help/repository/code-button.webp)

解凍して、フォルダの場所を覚えておいてください。

### 2. Chromeの拡張機能ページを開く

Chromeのアドレスバーに以下を貼り付けてEnter：

```
chrome://extensions/
```

### 3. デベロッパーモードをONにする

右上のトグルスイッチ **「デベロッパー モード」** をONにします。

### 4. フォルダを読み込む

**「パッケージ化されていない拡張機能を読み込む」** をクリック  
→ ダウンロードして解凍した **`ExtensionNote`フォルダ** を選択

ツールバーにメモアイコン（📝）が追加されれば完了です！

## 使い方

### メモを書く

1. メモしたいページを開く
2. ツールバーの 📝 アイコンをクリック
3. テキストボックスにメモを入力
4. タグを入力（任意）　例: `仕事, あとで読む`
5. **「保存」** をクリック

### メモを常に表示する

ポップアップの **「画面上にメモを常時表示」** をONにすると、  
そのページを開いているあいだ、右上にメモが表示されます。  
ドラッグして位置を移動できます。

### メモ一覧を見る・検索する

ポップアップ下部の **「📋 メモ一覧・検索」** をクリックすると、  
保存したメモを一覧で確認できます。

- テキスト検索（URL・タイトル・メモ内容）
- タグで絞り込み
- 新しい順 / 古い順 / タイトル順で並び替え

## データはどこに保存される？

この拡張機能のページ（`chrome-extension://...`）の **localStorage** に保存されます。  
クラウドには送信されません。あなたのブラウザの中だけに存在します。

## よくある質問

**Q. メモが消えた**  
A. Chromeの「閲覧履歴データの削除」でサイトデータを削除すると消えます。大切なメモはバックアップしてください（将来対応予定）。

**Q. 他のパソコンでも使いたい**  
A. 現在は同期機能がありません。同じパソコンのChromeのみで動作します。

**Q. Firefoxでは使えない？**  
A. 現在はChromeのみ対応しています。
